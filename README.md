# biel.dev — site institucional

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `styles.css`: identidade visual, layout e responsividade.
- `script.js`: menu mobile, ano automático e link do WhatsApp.

## Como visualizar
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

O site não precisa de compilação. As fontes externas usam Google Fonts; sem internet, o navegador usa fontes alternativas.

## Antes de publicar
- Confira o número do WhatsApp no `script.js` e no link de contato do `index.html`.
- Adicione links reais de redes sociais quando estiverem prontos.
- Substitua ou complemente o projeto-conceito Tríplice Fronteira App com capturas reais quando houver uma versão pública.
- Revise os preços e escopo dos serviços antes de divulgar.
